# Decisions

1. **Consume environment; do not generate it.** User clarification defines the ownership boundary. Preserve provided XML/JSON bytes and upstream flags; allow only a robot-composition wrapper. Avoid duplicate reconstruction work and unsupported semantic claims.
2. **Hierarchical policy via Strategy + adapters.** Reuse a geometric planner and controller; inject embodiment-specific actuator policies. Reject a universal actor across arbitrary MJCFs because observations, joints and control semantics differ. Registration occurs at one composition root. New compatible policy adapters must leave evaluator logic unchanged.
3. **G1 official PPO/LSTM artifact first.** Exact pinned 12DoF model has a small downloadable recurrent TorchScript checkpoint. Rejected generic Menagerie G1 and from-scratch SAC/PPO for the deadline. Cost: Torch runtime and strict model contract; no manipulation and no hardware-readiness claim. Sources and hashes: PRD.
4. **CPU inference before GPU specialization.** Route planning, IK and inference do not need gradient training. Reserve Modal credits until a measured baseline failure plus valid training setup justifies adaptation. Training must not be presented as zero-shot transfer.
5. **Fail-closed report plus replay.** One physics authority with explicit input, policy, and execution gates. A successful preview on unreviewed/assumed-scale geometry cannot become `SIM_READY`. Existing viewer consumes evidence; WASM exploration needs separate parity evidence to issue readiness.
6. **Direct local files over service infrastructure.** Single hackathon workflow does not justify a distributed trainer, database or new viewer. Input/report schemas and an explicit TypeScript bridge supply the integration seam.
7. **Conservative 2-D planning, 3-D verification.** Inflate provided projected boxes and validate actual robot motion in MuJoCo. A* clearance is an envelope calculation, not a complete swept-link or physical safety proof. Stop on real contacts/falls and report failures. No geometry repair when route is infeasible.
