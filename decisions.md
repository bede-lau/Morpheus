# Decisions

1. **Consume environment; do not generate it.** User clarification defines the ownership boundary. Preserve provided XML/JSON bytes and upstream flags; allow only a robot-composition wrapper. Avoid duplicate reconstruction work and unsupported semantic claims.
2. **Hierarchical policy via Strategy + adapters.** Reuse a geometric planner and controller; inject embodiment-specific actuator policies. Reject a universal actor across arbitrary MJCFs because observations, joints and control semantics differ. Registration occurs at one composition root. New compatible policy adapters must leave evaluator logic unchanged.
3. **G1 official PPO/LSTM artifact first.** Exact pinned 12DoF model has a small downloadable recurrent TorchScript checkpoint. Rejected generic Menagerie G1 and from-scratch SAC/PPO for the deadline. Cost: Torch runtime and strict model contract; no manipulation and no hardware-readiness claim. Sources and hashes: PRD.
4. **CPU inference before GPU specialization.** Route planning, IK and inference do not need gradient training. Reserve Modal credits until a measured baseline failure plus valid training setup justifies adaptation. Training must not be presented as zero-shot transfer.
5. **Fail-closed report plus replay.** One physics authority with explicit input, policy, and execution gates. A successful preview on unreviewed/assumed-scale geometry cannot become `SIM_READY`. Existing viewer consumes evidence; WASM exploration needs separate parity evidence to issue readiness.
6. **Direct local files over service infrastructure.** Single hackathon workflow does not justify a distributed trainer, database or new viewer. Input/report schemas and an explicit TypeScript bridge supply the integration seam.
7. **Conservative 2-D planning, 3-D verification.** Inflate provided projected boxes and validate actual robot motion in MuJoCo. A* clearance is an envelope calculation, not a complete swept-link or physical safety proof. Stop on real contacts/falls and report failures. No geometry repair when route is infeasible.
8. **Profile contracts over robot-name learner branches.** Mobile profile radius, body height and bounded command limits belong in `NavigationProfile`; the learner consumes that contract rather than testing `g1`, `stretch` or `go2`. This lets a profile be added without altering PPO/environment control flow, while preventing a fixed-arm profile from silently becoming a navigation target.
9. **A*-BC plus PPO is a disclosed local-navigation experiment.** The reduced-order 64x64 PPO actor-critic receives 23 local geometric/command observations and emits three body-velocity commands. A* local actions warm-start it before PPO because the deadline does not justify exploration-only convergence. Metadata reports random-init, warm-start, post-PPO and A* measurements separately, so PPO regression cannot be hidden. This is neither a replacement for the pinned G1 locomotion actor nor an ACT/foundation manipulation policy.
10. **Immutable learned artifacts and native hash gates.** A local policy checkpoint is valid only with its exact scene fingerprint, profile contract and SHA-256 metadata. The export adapter/viewer may label playback as learned-native only when learned and native report provenance agree; otherwise it blocks that claim. This keeps browser display and artifact discovery extensible without weakening physics authority.
11. **Direct-goal proxy success is not detour or visual-home evidence.** The robust CPU run (about 20 s/profile, Modal $0) reached 16/16 held-out proxy episodes for G1, Stretch and Go2 after stronger A*-BC+PPO; the earlier G1 run reached only 2/16. Every final held-out route was straight (polyline/direct = 1.0), so obstacle-detour learning is untested. The floor audit found 0 overlap between 973 mesh-supported samples and conservative 0.45 m G1-envelope-clear samples; proxy training cannot establish support on the visible floor. Global A* waypoints now feed the local actor with turn alignment, proximity slowing and predictive braking. A fresh seed-20007 native detour test passed 20/20 start perturbations, zero forbidden contacts, minimum clearance 0.10535 m. This narrow composite-controller evidence is separate from learned local-goal metrics; earlier failures remain recorded.
